# 基于字符级等长 token 化与多正样本对比学习的变长中文默读 EEG 解码



---

## 摘要

**背景与动机。** 从非侵入式脑电（EEG）直接解码语言（EEG-to-Text）是脑机接口的核心目标之一，
但 EEG 受试次时长不等、信噪比低、跨天跨被试漂移大等因素制约。已有的做法多把整段 EEG 压成定长向量，
使"句子长度"这一与语义无关的变量与"每个位置的时间点数"纠缠在一起。

**方法。** 本文提出一种**字符级等长 token 化**方案：利用 Chisco-2.0 中"每字固定 0.4 s"的采集约定，
把变长的 EEG 段按字边界无重叠切成形状恒为 $(C,T)=(122,100)$ 的 token，从而把"变长性"从**每个 token
的采样点数**转移到 **token 的个数**。每个 token 经共享权重的 TSConv 小 CNN 编码，加可学习位置编码后
送入 2 层 Transformer，再用**注意力池化**汇总成定长句嵌入，与冻结的 LaBSE 文本嵌入做**多正样本对称
InfoNCE** 对齐。train/val 按**句子**切分以避免泄漏，训练用**分组 batch 采样**保证同句跨天的多视图
互为正样本。

**结果。** 在 `sub-01`、`sub-02` 两被试的 day 1–4 默读条件上，`eeg2text` top-5 达 0.082/0.090，
`text2eeg` top-5 达 0.098/0.080，约为随机基线的 3.6–4.4 倍。三项对照进一步界定了该成绩的性质：
（i）**随机噪声对照**在完全相同架构/划分/评测下，全部指标精确钉在理论基线
（$train\_loss=\ln 128$、$val\_loss=\ln 900$、top-$k=1/N$），表明成绩来自真实脑电而非旁路泄漏；
（ii）**长度探针**显示 mean-pool 的句嵌入比注意力池化保留了更多可线性读出的 token 个数信息
（$R^2$ 0.408 vs 0.151），但这一差异**未**转化为检索优势；
（iii）**泛化边界**实验给出两个负结果——把整天留作 val（同句、留一天）时四折指标落在随机基线附近
（`val_loss` 7.040 vs 基线 7.025，`e2t@5` 0.0038 vs 0.0045），跨被试零样本迁移的 `val_loss`
（8.56）甚至**高于**随机基线（8.411）。

**结论。** 字符级等长 token 化能在**训练覆盖的个体与时段内**产出显著高于随机、且经得起泄漏对照检验的
EEG–文本检索；但当前表征是**句子特异**的，既不能跨天稳定对齐同一句，也不能零样本迁移到新被试。
我们把这一"高随机对照、零泛化"的组合如实报告，作为对 EEG-to-Text 现实可达性的一份谨慎证据。

**关键词：** 脑电；脑机接口；EEG-to-Text；对比学习；字符级 token 化；抗泄漏评测；跨被试泛化

## 1 引言

从大脑信号中解码语言，是脑机接口（BCI）最具吸引力也最具挑战性的目标之一。随着 Chisco、COFETT
等中文 EEG 语料库的公开，EEG-to-Text 研究具备了可比的数据基础 `[待核: Chisco, COFETT]`。然而，
与语音、文本等模态相比，EEG 有若干固有的建模障碍：**试次时长不等**、**单试次信噪比极低**、
**跨会话与跨被试的分布漂移大**。其中第一条尤其棘手——若把整段 EEG 直接压成定长向量，模型必须同时
面对"语义内容"和"这一段有多长"两种彼此纠缠的变异。

本文的出发点正是把这两者解耦。我们观察到 Chisco-2.0 采用"每字固定 0.4 s"的采集约定，因此在
250 Hz 下，每个字恰好对应 100 个采样点，且朗读段与默读段的时长分别是 $n_{\text{char}}\times100$ 与
$(n_{\text{char}}+1)\times100$——**恒为 100 的整数倍**。据此，我们提出**字符级等长 token 化**：
把一条试次的 EEG 按字边界无重叠切成若干形状恒定的 token，于是"变长"从 token 内部的采样点数
转移到 token 的个数。这样带来的直接好处是：所有字位置可以共享同一个 token 编码器（类似 ViT 的
patch embedding `[待核: ViT]`），从而避免参数随句子长度爆炸，并能泛化到训练中未见的句长。

以此为骨架，我们构建了一条完整的 EEG–文本对比解码流水线：共享权重的 TSConv token 编码器 →
2 层 Transformer → 注意力池化 → 与冻结 LaBSE 文本嵌入做多正样本对称 InfoNCE 对齐。同时，我们刻意
配套了**一整套对照与消融**，因为我们相信：在 EEG-to-Text 这类低信噪比任务上，"做出高于随机的指标"
与"证明这个指标来自脑信号"是两回事。一个模型完全可能借助句子长度、token 个数、数据划分等与信号
无关的旁路信息，伪造出看似合理的检索成绩。

本文的主要贡献可归纳为三点：

1. **方法层面**：提出字符级等长 token 化与配套的共享权重编码器、分组多视图采样，把变长 EEG 的
   建模问题转化为"定形 token + 变长序列"的标准序列建模问题。
2. **评测层面**：建立一套**抗泄漏评测协议**——随机噪声对照、长度探针、按长度分层的检索，用于区分
   "真实脑信号驱动的成绩"与"旁路信息制造的假象"。
3. **实证层面**：在给出高于随机的同被试成绩的同时，**如实报告两个负结果**（跨天不泛化、跨被试零样本
   失败），据此指出当前 EEG-to-Text 的现实可达性边界。

## 2 相关工作

**EEG-to-Text 解码。** 早期工作把 EEG 与文本词表做对齐，实现开词表的文本生成
`[待核: Wang & Ji]`；近期工作借鉴语音解码思路，用对比式目标从非侵入脑信号中提取语义表征
`[待核: Défossez et al.]`。这些方法多沿用"整段 → 定长"的编码范式。本文的区别在于显式利用数据的
**字级时长规律**做等长切分，从而在 token 层面统一形状、在序列层面保留句长。

**对比式表征对齐。** CLIP 式的对称 InfoNCE 已成为跨模态对齐的标准做法 `[待核: CLIP]`，其多正样本
推广则用于处理"一对多"的正样本结构 `[待核: InfoNCE]`。本文在其基础上引入**按句子分组的正样本掩码**，
以适配"同句跨天多视图"的数据结构。

**模态编码器。** 文本侧我们采用冻结的 LaBSE `[待核: LaBSE]`（Sentence-Transformers `[待核: SBERT]`），
它对中文句对检索有良好支持。EEG 侧的 token 编码器借鉴 NICE 的 TSConv 设计 `[待核: NICE]`；序列建模
采用标准 Transformer `[待核: Transformer]`，池化采用注意力池化 `[待核: Set Transformer]`。归一化
采用 GroupNorm `[待核: GroupNorm]` 以规避 padding 对照 batch 统计的污染。

**EEG 预处理。** 我们采用 PyPREP `[待核: PREP]` 做线噪去除、重参考与坏道插值，Autoreject
`[待核: Autoreject]` 估计拒绝阈值，ICLabel `[待核: ICLabel]` 做 ICA 成分自动标注，全部基于 MNE
`[待核: MNE]`。

## 3 方法

### 3.1 数据集

实验使用 **Chisco-2.0**（本地对应 OpenNeuro `ds006317`，即 COFETT）`[待核: COFETT]`。数据集为中文
脑电范式，每个试次包含两类与文本相关的事件：

- **朗读（reading）**：被试出声朗读句子；
- **默读 / 内语（inner speech）**：被试默读句子。

原始采样率 1000 Hz，含 122 个有效头皮 EEG 通道。通道集合取自 Chisco 1.0 的 `montage.csv`，仅保留
具有空间坐标的 122 个位置；坐标无效的 `10`、`111` 被剔除，`EKG`、`EMG`、`VEO`、`HEO`、`Trigger`
不作为头皮 EEG（其中 `VEO`/`HEO` 重标为 EOG）。

数据按 BIDS 组织，**day 与 session/task 的对应关系**如下：

| day | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| session | ses-01 | ses-02 | ses-03 | ses-04 | ses-01 | ses-02 | ses-03 | ses-04 |
| 文本集 | para1 | para1 | para1 | para1 | para2 | para2 | para2 | para2 |

其中 para1 的第 $k$ 个 run 对应文本文件 `text1-k`，para2 的所有 run 共享 `text2`。**因此同一批句子会在
day 1–4（或 day 5–8）之间跨会话重复出现**——这为后续"同句多视图"正样本提供了数据基础（见 §3.7）。
para1 共 1124 个唯一句子，每天录制一遍，故 `sub-01` day 1–4 共 4496 条试次。

本稿报告的主实验使用 **`sub-01`、`sub-02` 两个被试、day 1–4、`inner`（默读）**条件。

### 3.2 预处理

对每个 run 的 EDF 依次执行（实现见 `script/preprocessing.py`）：

1. **通道修正与蒙特区**：`VEO`/`HEO` 重标为 EOG；剔除无效 EEG 通道；设置 122 通道蒙特区
   （`on_missing="raise"`，保证任何缺坐标通道都显式报错而非静默丢弃）。
2. **事件标注**：由 `events.tsv` 的 onset（秒，与采样率无关）构建 `mne.Annotations`，事件编码映射为
   `Reading start (65329)`、`Inner-speech start (65379)`、`1.8 s rest start (65381)`、
   `long rest (65480/65481)`；未登记的事件编码直接报错。任务前导段、长休息段、尾部亦标注为坏段，
   由 MNE 自动排除。
3. **重采样**：1000 Hz → **250 Hz**（先写 annotations 再重采样，事件时刻不漂移）。
4. **PyPREP**：线噪去除（50 Hz 及其谐波）、重参考（全 EEG 通道）、坏道检测与插值（关闭 RANSAC）。
5. **1 Hz 高通**：仅作用于 EEG。PyPREP 去线噪时把趋势项加回，故在 autoreject / ICA 前显式高通。
6. **Autoreject**：在固定 2.0 s 长度的 EEG epoch 上估计拒绝阈值（供后续 ICA 拟合）。
7. **ICA 去伪迹**：`n_components=30`、infomax（extended）、`random_state=97`，在固定长度 epoch 上拟合；
   用 ICLabel 自动标注成分，仅保留 `brain` / `other`；随后用邻近通道插值仍坏掉的通道。
8. **落盘**：信号存为 FIF，文本与试次 onset 单独存为 `*_text.tsv` sidecar。

由 `script/summarize_text.py` 汇总所有 sidecar 为总表 `all_text.tsv`，按
`sample → subject → day → run → trial_index` 升序排列，并为每条试次计算：

- 起始采样点：`reading_sample = round(reading_onset × f_s)`，`inner_sample` 同理；
- **持续采样点数**：

$$\text{reading\_dur} = n_{\text{char}} \times 0.4 \times f_s,\qquad
  \text{inner\_dur} = (n_{\text{char}} + 1) \times 0.4 \times f_s,$$

其中 $f_s = 250$ Hz，即**每个字固定占 0.4 s**；$n_{\text{char}}$ 为句子的**非标点字符数**
（按 Unicode 类别剔除标点，即 `category[0] != 'P'`）。

### 3.3 字符级等长 token 化

这是本文方法的出发点：**把"变长"从每个 token 的采样点数，转移到 token 的个数**。

设采样率对应的 token 长度为

$$T = \text{round}(d_{\text{char}} \cdot f_s) = \text{round}(0.4 \times 250) = 100 .$$

由于 §3.2 中的段长均为 $0.4\,$s 的整数倍，**每条试次的段长必然可被 $T=100$ 整除**，因此可按字边界
无重叠切分：

$$(C,\, n_{\text{tok}} T) \;\xrightarrow{\text{reshape}}\; (n_{\text{tok}},\, C,\, T),$$

其中

$$n_{\text{tok}} = \frac{\text{dur}}{T} =
\begin{cases}
n_{\text{char}}, & \text{reading}\\
n_{\text{char}} + 1, & \text{inner}
\end{cases}$$

于是：

- 每个 token 的形状 $(C, T) = (122, 100)$ **恒定**，可复用同一套 token 编码器；
- 每条试次的 token 个数 $n_{\text{tok}}$ 可变 —— 在本数据上 $n_{\text{tok}} \in [5, 15]$，训练集均值
  约 9.45。

切分后不丢弃任何样本：本数据 day 1–4 的 4496 条试次**全部**能被 100 整除（无残缺 token）。

**数值约定**：FIF 中信号以伏特存储，读入后统一乘以 $10^{6}$ 转换为**微伏（µV）**。

**组 batch**：由于 token 形状已统一，collate 只需在 **token 数**这一维上 padding。对 batch
$\{n_{\text{tok}}^{(i)}\}_{i=1}^{B}$，取 $n_{\max} = \max_i n_{\text{tok}}^{(i)}$，得到

$$\text{tokens} \in \mathbb{R}^{B \times n_{\max} \times C \times T},\qquad
  \text{mask} \in \{0,1\}^{B \times n_{\max}},$$

pad 位置填 0，`mask=1` 表示有效 token。padding 代价极小（最多十几个位置）。

### 3.4 EEG 编码器

整体流程（结构示意图见 `paper/figs/fig_char_token_encoder.pdf`）：

$$\underbrace{(B, n, C, T)}_{\text{tokens}}
  \;\xrightarrow[\text{reshape}]{\text{共享权重}}\; (Bn, C, T)
  \;\xrightarrow{\text{token encoder}}\; (B, n, d)
  \;\xrightarrow{+\, \text{pos}}\; (B, n, d)$$
$$\xrightarrow{\text{Transformer}\times L}\; (B, n, d)
  \;\xrightarrow{\text{attn pool}}\; (B, d)
  \;\xrightarrow{\text{Linear}}\; (B, D)
  \;\xrightarrow{\text{L2 norm}}\; (B, D)$$

**逐 token 编码器（共享权重）。** token 编码器采用 NICE 风格的 TSConv 小 CNN。输入 $(N, C, T)$ 先
reshape 为 $(N, 1, C, T)$，依次经过：

| 层 | 配置 | 输出形状（$N{=}Bn$） |
|---|---|---|
| 时间卷积 Conv2d | $1 \to k{=}32$，核 $(1, m_1{=}9)$ | $(N, 32, C, T_1)$ |
| 时间平均池化 AvgPool2d | 核 $(1, m_2{=}13)$，步长 $(1, s{=}2)$ | $(N, 32, C, T_2)$ |
| GroupNorm + ELU | $\text{num\_groups}{=}1$，通道 $k$ | $(N, 32, C, T_2)$ |
| 空间卷积 Conv2d | $k \to k$，核 $(C, 1)$ | $(N, 32, 1, T_2)$ |
| GroupNorm + ELU + Dropout | dropout $=0.3$ | $(N, 32, 1, T_2)$ |
| 线性投影 Linear | $k T_2 \to d$ | $(N, d)$ |

其中 $T_1 = T - m_1 + 1 = 92$，$T_2 = \lfloor (T_1 - m_2)/s \rfloor + 1 = 40$，$k T_2 = 32 \times 40 = 1280$。

**三个设计选择与理由**：

1. **权重共享**：所有字位置共用同一套 token 编码器权重（相当于 ViT 的 patch embedding）。若按字符
   位置各用一套权重，参数量随句子长度爆炸，且无法泛化到未见过的句长。
2. **GroupNorm 而非 BatchNorm**：collate 会向 batch 注入 pad 出来的**全零 token**；BatchNorm 会把
   这些零样本计入 batch 统计量，污染真实样本的归一化。GroupNorm（$\text{num\_groups}{=}1$）是
   **逐样本**归一化，完全不受 padding 影响。
3. **时间卷积核刻意取小**（$m_1{=}9,\ m_2{=}13$）：输入仅 0.4 s，用大核会把时间信息压没。

**位置编码与 Transformer。** token 顺序即**字序**，位置信息必须显式给出。加入可学习位置编码
$\mathbf{p} \in \mathbb{R}^{1 \times M \times d}$（$M = \texttt{max\_tokens} = 32$，truncated normal，
$\sigma=0.02$）：$\mathbf{z}_j = \mathbf{h}_j + \mathbf{p}_j$。随后经 $L=2$ 层 `TransformerEncoder`：
$d=128$、注意力头数 4、前馈维度 256、dropout 0.1、激活 GELU、`norm_first=True`。padding 通过
`key_padding_mask = ~mask` 屏蔽，使 pad token 不参与注意力。**层数刻意取浅（$L=2$）**：token 数只有
5–15、数据量也小，层数一多极易过拟合。

**注意力池化。** 用一个可学习 query $\mathbf{q} \in \mathbb{R}^{1 \times 1 \times d}$（truncated normal，
$\sigma=0.02$）对有效 token 做加权汇总：

$$\mathbf{z}^{\text{pool}} = \mathrm{MHA}(\mathbf{q},\, \mathbf{H},\, \mathbf{H};\, \text{mask}) \in \mathbb{R}^{B \times 1 \times d}.$$

**为什么用 attention pooling 而不是 mean-pool**：token 个数恰好等于字符数，mean-pool 的输出统计量会
随 token 个数变化，理论上更容易让模型靠"平均了多少个 token"反推句子长度（**计数泄漏**）。可学习 query
的加权汇总表达力更强，故本文默认采用 attention pooling。但这一点**必须用实验说话，不能只凭直觉**
（协议见 §5.3.2）：结果显示该差异**没有**转化为检索优势，本文因此把它定位为"更少保留长度冗余"的
设计选择，而**不是**性能优势的来源。

最后经线性投影到共享嵌入维度并做 L2 归一化：

$$\mathbf{e} = \frac{W_{\text{out}}\,\mathbf{z}^{\text{pool}}}{\lVert W_{\text{out}}\,\mathbf{z}^{\text{pool}} \rVert_2}
\in \mathbb{R}^{D}, \qquad D = 768 .$$

本配置下编码器总参数量为 **723,680**（实测）。

### 3.5 文本编码器与共享嵌入空间

文本侧使用**冻结**的 **LaBSE**（`sentence-transformers/LaBSE`）：

$$\mathbf{t} = \frac{\mathrm{LaBSE}(s)}{\lVert \mathrm{LaBSE}(s) \rVert_2} \in \mathbb{R}^{768}.$$

- 参数全程冻结（`requires_grad=False`），仅前向，不参与梯度更新；
- 所有**唯一句子**的文本嵌入在训练前**一次性预计算**为查表 $\{s \mapsto \mathbf{t}_s\}$，训练时仅做
  索引，不重复前向 LaBSE。

两侧输出均为单位向量，因此**点积即余弦相似度**：$\mathrm{sim}(\mathbf{e}, \mathbf{t}) = \mathbf{e}^\top \mathbf{t}$。

### 3.6 对比目标：多正样本对称 InfoNCE

给定一个 batch 的 EEG 嵌入 $\mathbf{E} \in \mathbb{R}^{B \times D}$、文本嵌入 $\mathbf{T} \in \mathbb{R}^{B \times D}$
与温度 $\tau$：

$$\mathbf{S} = \frac{\mathbf{E}\,\mathbf{T}^\top}{\tau} \in \mathbb{R}^{B \times B}.$$

正样本由**句子 ID** 决定，而非对角线：令 $g(i)$ 为第 $i$ 条样本的句子组号，
$P_{ij} = \mathbb{1}[\,g(i) = g(j)\,]$。定义多正样本交叉熵（MP-CE，流程图见
`paper/figs/fig_mpce_flow.svg`）：

$$\mathrm{MP\text{-}CE}(\mathbf{S}, P) = -\,\frac{1}{B}\sum_{i=1}^{B}
  \frac{1}{\sum_j P_{ij}} \sum_{j=1}^{B} P_{ij}\,
  \Big( S_{ij} - \log \sum_{k=1}^{B} \exp S_{ik} \Big),$$

最终损失为两个方向的对称平均：

$$\mathcal{L} = \tfrac{1}{2}\Big[\mathrm{MP\text{-}CE}(\mathbf{S}, P) + \mathrm{MP\text{-}CE}(\mathbf{S}^\top, P)\Big].$$

由于 $P$ 对称，两个方向共用同一套正样本掩码。**性质**：

- 当一批中每个句子只出现一次时，$P$ 退化为单位阵，$\mathcal{L}$ 等价于标准 CLIP 式单正样本 InfoNCE；
- 当一批中同一句出现多次时（跨天多视图），同句的所有 trial **互为正样本**，不会被当作负样本互相推开
  （即避免**假负样本**）。

温度系数取 $\tau = 0.2$。注意：$\tau$ 的调参须在负样本数量足够的前提下进行，否则结果无参考价值。

### 3.7 多视图分组采样与数据划分

**按句子切分 train/val（8:2）**：以**句子**而非 trial 为切分单位，保证同一句子的所有 trial 只落在同一
侧。`sub-01` day 1–4 下切分结果为：train 899 句 / 3596 条 trial，val 225 句 / 900 条 trial，train/val
的句子集合**完全不相交**（重叠 = 0）。

**分组 batch 采样器**：每个 batch 抽取 `n_sentences = 32` 个**不同句子**，每句再抽 `n_repeats = 4` 条
trial，故 $B = 32 \times 4 = 128$（正样本掩码示意见 `paper/figs/fig_sampler_positive_mask.svg`）。
动机：句子只在**跨天**之间重复。若改用随机 shuffle，同一句的多个视图几乎不可能落进同一个 batch
（实测每 anchor 的平均正样本数仅约 1.03），多正样本机制等于空转。分组采样把它从"碰运气"变成
**确定性保证**：`pos/anch` 恒等于 `n_repeats = 4`。句子池按 `seed + epoch` 每轮打乱，保证可复现；
`n_repeats = 1` 可退化为随机 shuffle 的效果，用作消融对照。

### 4.2 评测协议与随机基线

两个检索方向的**候选池不同**，这是有意为之：

- **EEG → Text（`eeg2text`）**：候选池 = **去重后的唯一句子**（val 上 225 句）。同一句的多个 trial
  共享同一个文本向量，若不去重，同一句会占掉 4 个连续名次，`top-5` 实际只等于 top-2。
- **Text → EEG（`text2eeg`）**：候选池 = **全部 val EEG 样本**（900 条，彼此互不相同），命中判定为
  "前 $k$ 名中出现**任意同句**候选"。

指标：两方向的 `top-1` / `top-5`。**随机基线**（务必随表报告）如下表；`val_loss` 在全 val 集上以同一
分组 InfoNCE 计算，均匀分布下理论值为 $\ln 900 = 6.802$。

| 指标 | 候选池 | 随机基线 |
|---|---|---|
| `eeg2text top-1` | 225 个唯一句子 | $1/225 = 0.00444$ |
| `eeg2text top-5` | 225 个唯一句子 | $5/225 = 0.02222$ |
| `text2eeg top-1` | 900 条 trial（每 anchor 4 个同句正样本） | $4/900 = 0.00444$ |
| `text2eeg top-5` | 900 条 trial | $\min(5{\times}4/900,\,1) = 0.02222$ |

> 注：$n_{\text{val}} = 900$ 时单条翻转即造成 $1/900 \approx 0.11\%$ 的指标波动，`eeg2text_top1`
> 噪声较大，故模型选择默认按 `val_loss` 而非 top-1。

### 4.3 对照与消融协议

为区分"真实脑信号"与"旁路信息"，我们设置了四项对照/消融，每项**只改变一个变量**：

1. **随机噪声对照**（§5.2）：把 EEG 数值替换为独立同分布噪声，其余全部不变。
2. **池化消融与长度探针**（§5.3）：attn vs mean 两种池化；并用 ridge 回归直接检验句嵌入是否线性
   编码了 token 个数。
3. **跨天（留一天）泛化**（§5.4）：把整天划到 val。
4. **跨被试零样本迁移**（§5.5）：用 A 的权重预测 B 的数据。

## 5 结果与分析

### 5.1 主结果

在 day 1–4、`inner` 条件、30 epoch 训练下，两被试 `val_loss` 最优轮的指标如下（括号内为训练期峰值）：

| subject | best epoch | `val_loss` | `e2t@1` | `e2t@5` | `t2e@1` | `t2e@5` |
|---|---|---|---|---|---|---|
| sub-01 | 11 | **6.350** | 0.0111 | 0.0822（峰值 0.0933） | 0.0311 | 0.0978（峰值 0.1467） |
| sub-02 | 10 | **6.284** | 0.0144 | 0.0900（峰值 0.1156） | 0.0133 | 0.0800（峰值 0.1200） |
| 随机基线 | — | 6.802 | 0.0044 | 0.0222 | 0.0044 | 0.0222 |

两被试的 `eeg2text top-5` 约为随机基线的 **3.7–4.0 倍**、`text2eeg top-5` 约 **3.6–4.4 倍**（按峰值
更高），`val_loss` 均显著低于 $6.802$。这说明在**训练覆盖的个体与时段内**，字符级等长 token 化确实
支持了高于随机的 EEG–文本检索。

然而，两个细节提示训练并不充分：其一，两被试的 `val_loss` 都在 epoch 11–12 见底后回升，而检索指标
仍在缓慢爬升（例如 sub-01 的 `t2e@5` 从 best 轮的 0.098 持续升到末轮的 0.147）；其二，`eeg2text
top-1` 在 $1/900$ 的噪声量级上波动。因此下文所有对照都固定同一套配置与指标口径，以保证可比性。

### 5.2 随机噪声对照

**目的。** 验证 §5.1 的成绩来自**真实脑电信号**，而非与信号无关的旁路信息（架构、句子长度 / token
个数、数据划分）。

**设计。** 只改变一个变量——EEG 数值的来源。token 形状、$n_{\text{tok}}$、句子标签、train/val 划分、
采样器、损失、评测口径、模型、文本侧全部保持一致；把 token 的值替换为独立同分布随机噪声
$\tilde{\mathbf{x}}_i \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$，$\sigma = 1.0$。噪声**按样本索引
独立取种**，因此同一句跨天的多视图拿到互不相关的噪声（否则会人为制造"假对齐"）。默认
`--noise-refresh epoch`，即每个 epoch 重新采样，连"记住某一轮训练噪声"这条路也堵死。

**结果**（`sub-01`，day 1–4，30 epoch，$B=128$）：

| 指标 | 随机基线 | EEG 组 | 噪声组 |
|---|---|---|---|
| `train_loss` | $4.852=\ln 128$ | $3.45$（跌破基线） | $4.851$–$4.865$（$=$基线） |
| `val_loss` | $6.802=\ln 900$ | $6.350$ | $6.801$–$6.804$（$=$基线） |
| `eeg2text top-1` | $0.0044$ | $0.0111$（峰值 $0.0244$） | $0.0044$（恒定） |
| `eeg2text top-5` | $0.0222$ | $0.0822$（峰值 $0.0933$） | $0.0222$（恒定） |
| `text2eeg top-5` | $0.0222$ | $0.0978$（峰值 $0.1467$） | $0.0044$–$0.0533$（基线附近） |

**判读。** 噪声组的 `train_loss`、`val_loss` 与 `eeg2text top-1/top-5` 全部精确钉在理论基线上，
指标恒定不变还说明模型输出**塌缩为近乎常向量**、检索退化为一个固定的恰好等于随机的排序；而 EEG 组
显著优于随机。这支持"§5.1 的成绩来自真实脑电"，并**排除了"token 个数 = 句子长度"这类计数泄漏**——
噪声组的 token 形状与 $n_{\text{tok}}$ 分布与 EEG 组完全一致，却没有丝毫抬升。

### 5.3 池化消融与长度泄漏诊断

端到端检索指标在 900 条 val 上噪声过大（单条翻转 $=0.11\%$），不足以判定"计数泄漏"。因此我们直接
检验**句嵌入是否线性编码了 token 个数**，并对比两种池化。

#### 5.3.1 池化消融

除池化方式外，数据、损失、采样、划分、评测完全一致：

| 池化 | best `val_loss` | `e2t@1` | `e2t@5` | `t2e@1` | `t2e@5` |
|---|---|---|---|---|---|
| attention | **6.350** | 0.0100 | 0.0789 | 0.0178 | 0.0756 |
| masked mean | 6.355 | 0.0144 | 0.0678 | 0.0044 | 0.0844 |

两者的 `best val_loss` 仅差 $0.005$，各 top-$k$ 互有高低且差异全落在"单条翻转 $=0.11\%$"的噪声
量级内。**结论：不能断言 attention pooling 在端到端性能上优于 mean-pooling。**

#### 5.3.2 长度探针

冻住编码器，取 train/val 句嵌入，在 train 上拟合 ridge 回归 $\mathbf{e}\mapsto n_{\text{tok}}$
（特征标准化、目标中心化），在 val 上报告 $R^2$ / MAE / Spearman $\rho$；并以"打乱 train 标签后
重拟合"为零假设对照（应 $\le 0$）。另设**噪声输入对照**：把同一 checkpoint 的输入 token 换成独立
同分布噪声（保留 $n_{\text{tok}}$），给出"不含信号内容、仅凭 token 结构"能被线性读出的长度上界。

| 输入 · 池化 | val $R^2$ | val MAE | Spearman $\rho$ | 零假设 $R^2$ |
|---|---|---|---|---|
| attn · 真实 EEG | 0.151 | 1.309 | 0.431 | $-0.018$ |
| mean · 真实 EEG | 0.408 | 1.080 | 0.667 | $-0.028$ |
| attn · 随机噪声输入 | 0.404 | 1.075 | 0.642 | $-0.010$ |
| mean · 随机噪声输入 | 0.492 | 0.987 | 0.711 | $+0.015$ |

**结论。** 第一，mean-pool 的句嵌入比 attention pooling **保留了更多可线性读出的长度**（$R^2$ 约高
$2.7\times$）——这与 §3.4 开头的动机一致，即 attention pooling 确实更少保留长度冗余。第二，噪声输入
下两者 $R^2$ 进一步升高（0.40–0.49），说明这部分长度信息主要来自 token 的**个数/结构**而非信号内容。
第三，也是最关键的一点：即使长度被高度编码（噪声输入 $R^2 \approx 0.40$–$0.49$），其检索指标仍稳定
停在随机基线（`eeg2text top-5` $= 0.024$ vs 基线 $0.022$）——**长度可读 ≠ 检索制胜**。这呼应了 §5.2
的判读：仅凭长度编码不足以抬高检索成绩。

### 5.4 跨天（留一天）泛化

**目的。** §3.7 按**句子**随机切分，val 是**新句子**但来自**同一批天**；本节反过来把**整天**划到 val，
检验"同一句在未见过的某一天录到的信号"能否被识别。

**协议。** 在 day 1–4 上做 leave-one-day-out 四折，每折 3 天 train / 1 天 val；其余与主实验一致，
每折 `n_sentences=32`、`n_repeats=3`（$B=96$）、30 epoch 上限、seed 0，按 `val_loss` 选 best。
**关键前提**：para1 每天录的是**同一批 1124 句**，故 train/val 的句子集合**完全重合**——这里量化的是
**跨天稳定性**，与 §5.1 的"新句子泛化"不可直接比较。

**结果**（`sub-01`，每折 $n_{\text{val}}=1124$；随机基线 `e2t@1`$=1/1124=0.00089$、
`e2t@5`$=5/1124=0.00445$、`val_loss` 基线 $=\ln 1124 = 7.025$）：

| val day | `val_loss` | `e2t@1` | `e2t@5` | `t2e@1` | `t2e@5` |
|---|---|---|---|---|---|
| day-01 | 7.030 | 0.0009 | 0.0053 | 0.0018 | 0.0053 |
| day-02 | 7.065 | 0.0000 | 0.0027 | 0.0000 | 0.0009 |
| day-03 | 7.038 | 0.0009 | 0.0044 | 0.0000 | 0.0098 |
| day-04 | 7.027 | 0.0009 | 0.0027 | 0.0009 | 0.0027 |
| **mean ± std** | **7.040 ± 0.017** | **0.0007 ± 0.0004** | **0.0038 ± 0.0013** | **0.0007 ± 0.0009** | **0.0047 ± 0.0039** |

**判读。** 四折的 `val_loss`（$\approx 7.04$）与 `e2t@5`（均值 $0.0038$）都落在随机基线
（$7.025$ / $0.00445$）附近，甚至略低于随机——**没有出现跨天泛化**。这是一个值得注意的负结果：val
的句子全部在 train 中出现过（理论上模型"见过"这些句子），但换一天重新录制后，检索仍退化为随机。
它说明当前表征是**句子特异**的，不能在 session 之间对同一句的脑电形成稳定对齐。

### 5.5 跨被试零样本迁移

**目的。** 检验在 A 被试上训练的编码器能否**零样本**识别 B 被试的脑电。

**协议。** 用 A 的 best checkpoint 预测 B 的 day 1–4 数据；文本候选池是 target 的句子（被试间共享
同一批句子），损失与检索口径复用主实验评测。报告四个方向：两个同被试（工程上界参照）与两个跨被试。

**结果**（全员 day 1–4，$n_{\text{val}}=4496$，候选 1124 句，每 anchor 4 个同句正样本；随机基线
`e2t@1`$=0.00089$、`e2t@5`$=0.00445$、`val_loss` 基线 $=\ln 4496 = 8.411$）：

| 方向 | `val_loss` | `e2t@1` | `e2t@5` | `t2e@1` | `t2e@5` |
|---|---|---|---|---|---|
| sub-01 → sub-01 | 7.542 | 0.0162 | 0.0707 | 0.0596 | 0.1797 |
| sub-02 → sub-02 | 7.592 | 0.0122 | 0.0532 | 0.0383 | 0.1121 |
| sub-01 → sub-02 | **8.563** | 0.0013 | 0.0058 | 0.0009 | 0.0053 |
| sub-02 → sub-01 | **8.568** | 0.0009 | 0.0047 | 0.0009 | 0.0036 |

> 同被试两行在**全数据集**（含其自身训练 trial）上评测，故高于 §5.1 中 225 句 val 上的指标，仅作
> 工程上界参照；跨被试两行才是真正的零样本评测。

**判读。** 跨被试两方向的 `val_loss`（8.56）**高于**随机基线 8.411，`e2t@5` / `t2e@5` 全部落在随机
基线（0.00445）附近——**当前编码器无法零样本跨被试迁移**。结合 §5.4，泛化域同时受限于**个体**与
**session**。

## 6 讨论

### 6.1 主要发现

本文的实证结果可以概括为一个"**高随机对照 + 零泛化**"的组合：

1. **同被试成绩真实且经得起对照。** 在训练覆盖的个体与时段内，`eeg2text`/`text2eeg` 的 top-5 约为
   随机的 3.6–4.4 倍（峰值更高），且经随机噪声对照检验——噪声组全部指标精确回到理论基线，说明这部分
   成绩依赖真实脑电，而非架构、句长或划分的旁路泄漏。
2. **注意力池化不是性能来源，而是"少留长度"的选择。** 池化消融显示 attn 与 mean 在端到端指标上
   不可区分；长度探针进一步说明 attention pooling 的句嵌入确实更少编码长度，但这一"好处"并未转化为
   检索优势。我们因此不把池化当作贡献点。
3. **泛化边界明确。** 跨天（同句、留一天）与跨被试两个方向都退化为随机，且跨被试的 `val_loss` 甚至
   高于随机基线。这表明模型学到的是**句子 × 天 × 个体**高度耦合的表征，而非可迁移的语言语义。

### 6.2 泛化边界的可能成因

跨天负结果尤其值得讨论：val 的句子在 train 中**全部出现过**，若模型学到的是稳定的"句子指纹"，理论上
应该能匹配；实测却退化为随机。可能的原因包括：其一，EEG 的会话内漂移（电极阻抗、注意力、疲劳）远大于
句间差异，导致同一句在不同天的表征不稳；其二，训练集里同一句只提供 4 个视图（4 天），且 `val_loss`
在 epoch 11 后即回升，模型更倾向于记住"训练那几天的样本"，而非抽取跨天不变的结构；其三，当前对比目标
只拉近同句跨天视图、推远不同句，并未显式建模或归一化 session 变量，因此无法抑制会话偏移。

这三点与跨被试结果指向同一结论：**在没有显式的域适应 / 会话归一化设计之前，EEG-to-Text 的可迁移性
非常有限**。这也是我们认为必须如实报告负结果的原因——它直接界定了方法当前的适用边界。

### 6.3 局限

- **规模与统计强度**：仅 2 被试、单种子、单语料（day 1–4 / para1），且 30 epoch 内 `val_loss` 已
  见底回升，尚未训到收敛；跨天实验未跨 para（句子池不同）。主结果应补充多种子与置换检验 / bootstrap
  置信区间。
- **对照覆盖不全**：已完成噪声对照、池化消融、长度探针、跨天留一、跨被试；仍缺 GroupNorm vs
  BatchNorm、token 时长（0.4 s vs 0.2 s）、采样器（`n_repeats=1` vs 4）等消融，以及强 baseline
  对比。
- **噪声类型单一**：噪声对照用 iid 高斯；建议补充**保留功率谱的相位打乱**或**跨 trial 置换**，以验证
  "是否只有与文本相关的成分在起作用"。
- **评测口径**：跨被试与跨天实验的候选池规模（1124 / 4496）与主实验（225 / 900）不同，跨实验的
  top-$k$ 不可直接横比，本文已分别随表给出各自的随机基线。

---

## 7 结论

本文提出**字符级等长 token 化**：利用数据中"每字固定 0.4 s"的规律，把变长 EEG 按字边界切成形状
恒定的 token，把变长性转移到 token 个数，从而用共享权重编码器 + Transformer + 注意力池化 + 多正样本
对称 InfoNCE 完成 EEG–文本对齐。配套的**抗泄漏评测**（随机噪声对照、长度探针、按长度分层检索）表明：
同被试成绩来自真实脑电、不依赖句长或架构旁路；但**跨天与跨被试两个方向的泛化都退化为随机**，当前
表征是句子特异的。我们把这一"高随机对照、零泛化"的结果如实呈现，希望为 EEG-to-Text 的现实可达性
讨论提供一个可复现、可对照的经验基线。后续工作将聚焦于会话/被试域的显式归一化与更大规模、多种子的
验证。
